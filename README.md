# Gireesh & Anjana wedding invitation

A responsive, single-page invitation styled as a keepsake card. Visitors can open and close the envelope, expand the ceremony and reception details, view a live countdown, open venue searches in Google Maps, share the page link, and open the shared Google Drive photo album to view or contribute pictures.

The wedding portrait is generated from the couple-photo references in the conversation, with traditional Indian attire and a soft watercolor garden setting. AI-generated portraits can introduce subtle differences from the source faces.

## View locally

Open `index.html` in a browser, or serve this folder with any static web server. For example, from this folder run `python3 -m http.server 8000` and visit `http://localhost:8000`.

The venue buttons search Google Maps by the printed venue names and towns. Replace those links with exact pin URLs if you have them. Google Drive controls who can view or add photos; guests may need to sign in to upload.
